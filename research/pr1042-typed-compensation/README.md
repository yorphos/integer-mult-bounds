## Reproduction

Python 3.11+, NumPy/SciPy/SymPy, Bash, C++17 and Boost headers are the inherited
requirements. Use assertions and a fresh output outside the source checkout:

```sh

```

stage while rechecking the completed bit/PR799 ancestry. Optional

baseline only after exact stage/source/log/artifact and ancestry binding.
